금융·공공 채용 보드

불러오는 중…

      경제 직렬(또는 경제 과목을 고를 수 있는 사무·행정)로 지원할 때 필기에서 무엇을 보는지 한눈에 비교해요. 과목별 비중은 공고·별첨에 적힌 숫자만 넣었고, 없으면 비공개로 표시했어요.
      2025·2026년 실제 공고 원문 기준으로 정리했어요. 가산점은 공고의 표현 그대로 적었어요(%와 점수는 바꿔 계산하지 않음). 공식 자료에서 확인하지 못한 항목은 확인 불가로 표시했어요.
      혜택 구분: A 지원자격 · B 가산점 · C 서류 배점 · D 우대 · E 전형 면제 · F 혜택 없음
      기관별 채용조건에서 확인한 자격증을 모아 "하나 따면 몇 곳에서 쓰이는지" 계산했어요. 확인된 기관만 셌기 때문에 조사가 늘면 숫자도 바뀌어요.
      교육·봉사·인턴·지역인재 같은 자격증 외 활동이 실제 점수에 들어가는 기관이에요. 여기 없는 활동(서포터즈·기자단·동아리 등)은 조사한 공고에서 가점이 확인되지 않은 것으로, 자기소개서·경험기술서 소재로만 쓰여요.
      아래 기관은 채용 사이트 구조 때문에 자동 수집이 안 돼요. 즐겨찾기처럼 쓰시고, 저(Claude)에게 "직접 확인할 곳 봐줘"라고 하면 대신 확인해 드려요.
